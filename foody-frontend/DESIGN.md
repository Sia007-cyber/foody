# یادداشت طراحی — Foody Frontend

سبک: زبان بصری الهام‌گرفته از اپل، برای یه محصول فارسی/راست‌به‌چپ. بدون
عکاسی واقعی (چون محتوای واقعی نداریم) — به‌جاش از رنگ تخت + لکه‌های محو
رنگی (blob) به‌عنوان امضای بصری استفاده شده.

## پالت
- `--paper` #ffffff — پس‌زمینه‌ی اصلی
- `--mist` #f5f5f7 — سطح ثانویه (اپلی، برای سکشن‌ها/پس‌زمینه‌ی داشبورد)
- `--ink` #1d1d1f — متن اصلی
- `--ink-soft` #6e6e73 — متن ثانویه
- `--ember` #ff5a36 — رنگ برند Foody (قرمز هلویی/اشتها-برانگیز، عمداً متفاوت
  از رنگ کلود #D97757 و از آبی‌های عمومی SaaS)
- `--ember-deep` #e2431f — حالت hover/active رنگ برند
- رنگ‌های وضعیت (فقط برای پیل‌های status): سبز تایید‌شده، قرمز رد‌شده،
  خاکستری در انتظار، قرمز تیره معلق

## تایپوگرافی
یک خانواده: **Vazirmatn Variable** (وزن‌های ۴۰۰ تا ۸۰۰) — هم برای
هدینگ هم بدنه. معادل فارسی SF Pro از نظر کیفیت و مدرن بودن.
اعداد لاتین (نه فارسی) برای قیمت/تاریخ — مطابق با اکثر محصولات مدرن ایرانی.

## اصول
1. رنگ ember فقط برای CTA اصلی، قیمت، و حالت‌های فعال — بقیه‌ی صفحه خاکستری/سفید.
2. هیچ عکس استوکی نیست؛ رنگ تخت + بلاب‌های محو جای عکس رو می‌گیرن.
3. دو رجیستر بصری، یک سیستم تایپ: سطح مشتری (Discover/Business/Checkout)
   فراخ و مطمئنه (تایپ بزرگ)، پنل‌های owner/admin چگال و کاربردی‌ان
   (ردیف‌های گروه‌بندی‌شده به‌جای کارت‌های شادو‌دار تکراری) — ولی هر دو از
   همون فونت/رنگ/زبان گردی استفاده می‌کنن.
4. وضعیت همیشه با پیل رنگی + کلمه‌ی فارسی نشون داده می‌شه، نه فقط رنگ.
5. حرکت: فقط یک ورود هماهنگ (هدلاین + جستجو در صفحه‌ی Discover) + hover lift
   روی کارت‌ها. نه فید-اسلاید روی هر بخش.

## چیزهایی که عمداً ازشون پرهیز شد (تا کلیشه نشه)
- بدون لیبل ALL-CAPS، بدون eyebrow بالای هدینگ
- بدون '→' در انتهای دکمه‌ها
- بدون فونت مونو برای اعداد/لیبل
- کارت‌های owner/admin شادو-یکسان ندارن؛ اونجا لیست ردیفی با خط جداکننده‌س
